# Ham veri

Ham veri bu depoya **yüklenmemiştir**. Kaggle'dan indirilebilir:

**Rossmann Store Sales** (Kaggle yarışması): https://www.kaggle.com/competitions/rossmann-store-sales

Bu çalışmada kullanılan dosyalar:
- `train.csv` (1.017.209 satır; 2013-01-01 – 2015-07-31 arası günlük mağaza satışları)
- `store.csv` (1.115 mağazanın tipi, ürün çeşidi ve rakip bilgisi)

Kullanım koşulları için Kaggle'daki *Rules* sayfasına bakınız.
